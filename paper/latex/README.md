# IJAR LaTeX source

Compile with pdfLaTeX, BibTeX, and two further pdfLaTeX passes. The official
elsarticle class and elsarticle-num style are included unchanged. All source
files share the archive root for Editorial Manager. The .bbl file is included.
Figures are individual vector PDFs; tables and equations remain editable TeX.

The journal uses single-anonymized review. Author identities are retained.
The user supplied the complete saved official Guide for Authors; its relevant
formatting requirements were checked on 23 September 2026. Manuscript source
files must be uploaded as manuscript/LaTeX source items, not supplementary items.

The authors still need to complete the official declaration tool and confirm
the data-repository requirement and final author-managed submission statements.
